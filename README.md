# 🧪 SBER_DEFI_HACK_2025 (05.2025)

**SafeDeFi** — платформа для мониторинга, анализа и отслеживания изменений в смарт-контрактах, разработанная в рамках **SBER DeFi Hack 2025**.  
Проект включает **веб-приложение**, **Telegram-бота** и **микросервисную архитектуру** на базе **FastAPI, Node.js и PostgreSQL**.

Платформа позволяет:
- анализировать смарт-контракты и выявлять потенциальные уязвимости;
- отслеживать обновления прокси-контрактов;
- уведомлять пользователей об изменениях в реальном времени;
- предоставлять доступ к основному функционалу как через сайт, так и через Telegram-бота.

---

## Моя роль в проекте

В проекте я занимался **backend-разработкой, авторизацией, frontend-частью, Telegram-ботом и деплоем**.

### Что конкретно было сделано:
- спроектировал **микросервисную архитектуру backend**;
- разработал структуру **базы данных** и **REST API**;
- реализовал **авторизацию и аутентификацию**:
  - **OAuth2**;
  - **JWT Access / Refresh Tokens**;
  - хранение refresh token в **HttpOnly cookie**;
  - привязку **Telegram-аккаунта** к профилю пользователя на сайте;
- разрабатывал **клиентскую логику** веб-приложения;
- проектировал и реализовывал **интерфейсы**, **стили** и **адаптивный дизайн**;
- внедрил **FSD (Feature-Sliced Design)** для организации frontend-архитектуры;
- написал **Telegram-бота** для уведомлений об изменениях в смарт-контрактах;
- реализовал в боте **дублирование основного функционала сайта**;
- занимался **сборкой и деплоем** проекта на сервере **Ubuntu**;
- настроил инфраструктуру и запуск сервисов через **Docker Compose**.

---

## Стек технологий

**Backend:** Python, FastAPI, Node.js, PostgreSQL, SQLAlchemy  
**Frontend:** React, TanStack Query, FSD  
**Bot:** aiogram  
**DevOps / Infra:** Docker, Docker Compose, Ubuntu  
**Auth / Security:** OAuth2, JWT, HttpOnly Cookie
